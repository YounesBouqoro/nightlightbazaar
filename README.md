# Night Light Bazaar

Landingpage für das Night-Shopping-Event **Night Light Bazaar** in Düsseldorf.

## Positionierung

Clean, modern und atmosphärisch: Night Market × Fashion & Vintage × DJ Culture × Food × Drinks.

## Lokale Entwicklung

```bash
npm install
npm run dev
```

Danach läuft die Seite unter `http://localhost:3000`.

## Aktueller Stand

- Responsive Onepage
- Hero und visuelles Brand-System
- Concept- und Experience-Sektionen
- Partnerbereich
- Event-Info mit Platzhaltern für Datum und Location
- Vorbereitung für spätere Vendor-/Partner-Bewerbungen

Datum, Location, DJs, Händler, Foodstände und Ticketing werden ergänzt, sobald die Details feststehen.
